ALMI CHAIN - WEB DE DEMOSTRACION

1. Abre index.html con Live Server en Visual Studio Code.
2. La seccion Ubicacion incluye un mapa interactivo de OpenStreetMap centrado en Bilbao; se carga al pulsar "Ver el mapa" (script.js).
3. Sustituye el telefono, horario, enlace y coordenadas del mapa por los datos definitivos del restaurante.
4. El formulario es un placeholder y no envia datos.

Archivos:
- index.html: estructura, contenido y mapa.
- img/: fotos de la web en WebP; autores en img/CREDITOS.txt.
- style.css: diseno editorial, responsive y accesible.
- script.js: menu movil, slideshow, geolocalizacion y formulario demo.
